Added and accepted a confined ls-like metadata application using live fs_walk and file_metadata. It displays deterministic lexical names, portable kinds, logical sizes, exact Unix milliseconds, and UTC ISO text; synthetic rows prove timestamp ties and unavailable-last behavior. Native mlplunit covers ordering, dates, boundaries, and malformed metadata. A macOS/Linux host oracle verifies kind, size, and timestamp seconds, while confined probes verify normal, missing, and symlink-escape behavior. Full just check passes 124 tests across 36 suites.
