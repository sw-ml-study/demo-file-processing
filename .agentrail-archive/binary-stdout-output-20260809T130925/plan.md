# Binary stdout output

1. write_stdout conformance

Probe and stabilize validation, exact counts, empty writes, binary byte preservation, per-call ordering/flush behavior, stderr separation, broken-pipe errors, and interpreter/compiler boundaries.

2. bounded stdout copy and demonstrations

Build bounded read-range to write_stdout loops with explicit chunk/total budgets, exact binary shell oracles, self-describing stderr narration that never contaminates stdout, and interesting byte/WAV/Ogg output examples.

3. stdout acceptance and reconciliation

Measure growing binary-stdout RSS through a file/pipe sink, run the full gate, stabilize stdout APIs, reconcile README/catalog/plans/sagas/capabilities/upstream contracts, and publish only the remaining compiler, packed-byte, source-handle, and codec blockers.
